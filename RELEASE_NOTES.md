# Release Notes

User-facing release notes for all versions.

## v0.1.4

_Релиз от 2026-05-31_

### Новые возможности

- **Графики трендов по этапу.** Помощник строит наглядные графики динамики во времени для выбранного этапа: золото/час, опыт/час и время прохождения. Каждая точка — реальный завершённый забег; при наведении показывается значение и дата/время.
  - Этап выбирается из списка тех, по которым уже накоплена история; графики мгновенно перестраиваются при смене этапа.
  - Открываются кнопкой «Графики» в виджете; при отсутствии истории показывается понятная заглушка.
  - Так завершён третий и последний крупный сценарий — теперь доступны живая статистика, сравнение этапов и тренды во времени.

### Под капотом

- Добавлен механизм аккуратного прореживания старых промежуточных замеров (для контроля размера локальной базы) — при этом история забегов и рассчитанные агрегаты по этапам полностью сохраняются.

---

_Все данные остаются локальными на вашем ПК. Сборка без ошибок и предупреждений; покрытие тестами на реальной базе SQLite._

## v0.1.3

_Релиз от 2026-05-31_

### Новые возможности

- **История этапов и выбор оптимального для фарма.** Помощник накапливает историю забегов по всем 60 этапам и на экране сравнения ранжирует их по выбранной цели (золото/час ↔ опыт/час), подсвечивая рекомендованный этап.
  - **Рекомендация учитывает силу отряда.** Добыча растёт с уровнями героев, предметами и рунами, поэтому рекомендация считается по **недавним** забегам (текущая сила), а не по усреднению за всю историю — иначе совет был бы основан на устаревших данных слабого отряда. Можно переключиться на режим «вся история» для справки.
  - Для каждого этапа виден контекст силы (диапазон уровня/урона), а забеги, сделанные при заметно меньшей силе, чем сейчас, помечаются как «устаревшие».
  - Переключение цели оптимизации (золото/час ↔ опыт/час) мгновенно пересчитывает ранжирование и рекомендацию.
  - История переживает перезапуск помощника и перезагрузку ПК.

### Известные ограничения

- Запись завершённых забегов активируется после калибровки областей основной игровой зоны (прогрессбар/босс/время этапа) — до этого экран сравнения показывает «нет данных». Полные предметы/руны и герои 2–3 отряда в этой версии не считываются (учитывается выбранный герой как показатель силы).

## v0.1.2

_Релиз от 2026-05-31_

### Новые возможности

- **Живая статистика забега (MVP).** Компактный виджет рядом с игрой в реальном времени показывает золото/час, опыт/час, сундуки/час, класс/уровень/урон героя и текущий этап — данные считываются визуально с экрана игры (захват окна + распознавание), без вмешательства в игру.
  - Виджет перемещается, опционально закрепляется поверх других окон; позиция и размер запоминаются между запусками.
  - Понятные состояния: «Игра не найдена», «Ожидание окна», метка устаревания данных, когда окно свёрнуто или перекрыто.
  - Экран калибровки областей считывания (ROI) для настройки под ваше разрешение и масштаб.
- Темпы считаются корректно при смене уровня героя и не занижаются за периоды, когда окно игры было недоступно.
