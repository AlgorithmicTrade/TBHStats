# T051 — Acceptance Smoke Checklist (live)

**Фича:** `001-tbh-stats-helper` · **Задача:** T051 · **Дата:** 2026-05-31 · **Переработан:** 2026-06-01 (по итогам живой калибровки)
**Назначение:** пошаговый ручной прогон приёмки на **реально запущенной игре Task Bar Hero**. Отмечай `[x]` по мере выполнения, вписывай фактический результат/замер в поле «Факт».
**Среда:** Windows 11, .NET 8 SDK, установленная игра TBH. Все команды — из корня `G:\Project-X\TBHStats`.

> Источники критериев: `spec.md` (SC-0xx, FR-0xx), `quickstart.md`, а также решения живого прогона — **ADR-019** (мульти-панельный UI), ADR-018 (раскладка сундуков), GAME-FACTS §2/§5–§6.
> 🟢 PRE-VERIFIED — подтверждено статически; на живом прогоне лишь подтвердить.

### Важные уточнения после живого прогона 2026-06-01 (читать перед прогоном)

- **Несколько разделов открыты ОДНОВРЕМЕННО** (3 слота над MainZone: левый `Status`, центр `Hero`, правый `Cube/Portal`; оверлей `Rune`; `gold` глобально вверху). Модель «одной активной вкладки» снята: поля читаются **с фиксированных позиций каждый кадр**, без gating по `activeTab` (ADR-019).
- **Калибровка** имеет **живой OCR-предпросмотр** (кнопка «Проверить OCR» + «Копировать»): обведи ROI → сразу видно распознанный текст и уверенность. Это основной инструмент точной разметки.
- **Порог уверенности** приёма поля = **0.02** (метрика — геометрическое покрытие, низкая для коротких чисел; основная валидация — парсер+sanity).
- **Локаль значений:** пробел = разделитель тысяч, **запятая = десятичный разделитель** («392,8» = 392.8 → урон 392).
- **ROI перечитываются каждый кадр** — правки калибровки применяются **без перезапуска** (~1.5 с).
- **Режим «поверх всех окон» отключён** (виджет не закрепляется поверх).
- **P2 (не в этом прогоне):** подсчёт **сундуков** (графические точки, не OCR — T062), завершение этапа/время по **`stageProgress`** (T063), `stageId` по зелёному флагу Portal (T064). Эти пункты помечены ⏸ P2.
